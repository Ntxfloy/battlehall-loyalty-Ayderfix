# Фирменные шрифты

Сюда нужно положить лицензионные файлы шрифтов клуба — те же, что стоят
на battlehall.ru (`/wp-content/themes/invader/assets/`):

- `Plateia-Bold.woff`      — заголовки (в брендбуке: «основной шрифт заголовков второго уровня»)
- `Gilroy-Regular.woff`    — основной текст
- `Gilroy-Medium.woff`
- `Gilroy-SemiBold.woff`
- `Gilroy-Bold.woff`

Файлы намеренно не закоммичены: это платные гарнитуры, права на них
у клуба. Пока их нет, интерфейс работает на системных шрифтах —
вёрстка не ломается, теряется только фирменный характер типографики.

Шрифт `BATTLEHALL` (из логотипа) в интерфейсе не используется: по брендбуку
он только для логотипа и заголовков первого уровня в рекламе.
