# Ключи сервисных аккаунтов

Сюда кладётся JSON-ключ сервисного аккаунта Google — файл вида
`google-service-account.json`. Путь к нему указывается в `.env`
в переменной `GOOGLE_CREDENTIALS_FILE`.

Папка внесена в `.gitignore`: ключ даёт доступ на запись в таблицу,
его нельзя коммитить и пересылать в мессенджерах.
